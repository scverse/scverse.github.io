    scverse

    Foundational tools for single-cell omics data analysis

    Scverse is an open-source, community-governed ecosystem of packages for single-cell and spatial omics. Shared data structures like AnnData, MuData, and SpatialData let tools such as Scanpy, scvi-tools, and Squidpy compose into a single powerful analysis.

    For researchers

    Well-documented, actively maintained tools that interoperate out of the box.

    For developers

    Shared data structures and conventions, so your package fits the ecosystem from day one.

    For institutions

    A community-governed foundation ensuring the long-term maintenance of critical infrastructure.

    import scanpy as sc
    sc.pl.umap(data, color='clusters')
    What every core package provides
    Documentation

    Extensive documentation covering installation, usage, and API references for every core package.

    Stable releases

    Semantic versioning and changelogs for every release.

    Open source

    Freely licensed and hosted on GitHub — use it, modify it, fork it.

    Continuously tested

    Every change runs through CI before release.

    Interoperable

    Shared data structures mean output from one tool works as input to the next.

    Community governed

    Roadmap and priorities are set by the community and core developers, not a single company.
